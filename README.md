# The Conway's game of life
This is a school project in which I created a web-based Conway's game of life. 

![MIT License](https://img.shields.io/badge/license-MIT-blue.svg)
![JavaScript](https://img.shields.io/badge/language-JavaScript-F7DF1E.svg)

## About ([Wikipedia definition](https://en.wikipedia.org/wiki/Conway's_Game_of_Life)) :
The Game of Life, also known as Conway's Game of Life (sometimes abbreviated as CGoL) or simply Life [...] is played on an infinite square grid, with each cell being in one of two states: live or dead. Cells in configurations called patterns evolve over generations according to the number of live and dead cells in their Moore neighborhood, that is, the eight cells in their immediate proximity.
## Features :

| Feature | Description |
|---------|-------------|
| **Customizable Grid** | Adjust grid dimensions to your preference |
| **Speed Control** | Configure ticks per second for simulation speed |
| **Playback Controls** | Play, pause, and step through generations |
| **Reset Functionality** | Clear board and start fresh anytime |
| **Dark Mode** | Easy-on-the-eyes interface |
| **Responsive Design** | Works on desktop and mobile devices |

## Installation & Usage

Since this is a static web application, no build process is required:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Keaexe/gameOfLife.git
   cd gameOfLife
   ```
2. **Use in your browser**
   + By click-dragging
   + By double clicking

You can host this as well but I won't cover the installations steps
